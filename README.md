# Dr. P. R. Neethu – Portfolio

Personal portfolio website (plain HTML, CSS and JavaScript, no build step).

## Structure
- `index.html` – page content
- `style.css` – styling (light/dark theme, responsive)
- `script.js` – mobile menu, theme toggle, publication filter, active-link highlight
- `assets/photo.jpg` – profile photo

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy
Push to GitHub and enable GitHub Pages (branch `main`, folder `/root`), or drop the folder onto Netlify or Vercel.
